Autenticación en Dos Pasos (2FA)

El 2FA agrega una capa extra de seguridad usando una app como Google Authenticator o Authy en tu celular.

Instrucciones:

  1. Abre tu app de autenticación (Google Authenticator, Authy, etc).
  2. Escanea este código QR.
  3. Ingresa el código de 6 dígitos que genera la app para confirmar.
